Обновляй только ProductCode!


Тут есть некоторая путаница, связанная с тем, что windows installer допускает тесколько "стратегий" для обновления.
Самая простая и распространенная — "major upgrade". Она подразумевает, что старая версия (1.4) целиком заменяется новой (1.5). То есть, старая версия удаляется, новая ставится. 
При таком обновлении ProductCode должен (обязан) меняться. А для идентификации продукта для обновления (удаления) существует — сюрприз — еще один код — UpgradeCode 

RTFM HOWTO: Implement a Major Upgrade In Your Installer http://wix.sourceforge.net/manual-wix3/major_upgrade.htm
