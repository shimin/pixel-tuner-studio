## Расхождения

| Область | master | claude/… | Вывод |
| --- | --- | --- | --- |
| Раскладка | `EpicCore` с аудио и настройками; логика окна в `AppModel` внутри приложения (443 строки) | `EpicCore` / `EpicPlayerKit` / `EpicPlayerMac` / `EpicProbe` | **claude.** Модели проверяются `swift test` на фейках, без UI |
| Адреса интерфейсов | `sockaddr_in` читается из байтов самого указателя: на этом Mac у всех интерфейсов вышел `12.0.0.0` | читается правильно: `en0 192.168.1.102/24` | **claude.** Ошибка master — блокер: broadcast не дошёл бы до устройства. Тест master её не ловил, проверял только непустой список |
| Тип интерфейса | по префиксу имени (`en*` — Ethernet) | флаги, префиксы и `NWPathMonitor` (Wi-Fi / Ethernet) | **claude.** Точнее фильтр, понятнее подпись в списке |
| Привязка сокета | bind на адрес интерфейса, без `IP_BOUND_IF` | bind `0.0.0.0` + `IP_BOUND_IF` + `SO_REUSEPORT` | **claude.** На macOS сокет на unicast-адресе не получает broadcast, а `IP_BOUND_IF` держит пакеты на `en0` при VPN — проверено |
| Колбэки сокетов | приём на фоновом `Thread`, в приложении — `MainActor.assumeIsolated`: по коду падение на первом ответе устройства или пакете Art-Net (не запускал) | `DispatchQueue.main.async`, затем модель | **claude.** Второй блокер master; путь claude проверен — Art-Net управлял приложением |
| Тестируемость сети | `SocketBackend` + двойники: логика приёма в тестах, реальный обмен — отдельный `.app`-зонд | чистая логика в тестах, живые сокеты — через `epic-probe` | **claude.** Проще; обмен проверен в живой сети с имитаторами |
| Ответ устройства | `0x49`, длина > 3, CP1251 | то же | совпало. Эталоны master подтверждают |
| Art-Net | `ArtNetParser` + эталоны `artnet-vectors.json` | `ArtDmx` + `DmxTrigger`, без эталонов | **код claude, эталоны master** — совпали. Комментарий master «OpCode big endian» неверен: байты `00 50` — это little endian |
| Повторы в сеть | play раз в секунду, только пока растёт позиция | play раз в секунду; stop @ 0 раз в секунду, пока стоп | **claude.** Повтор stop — поведение Windows, на него, видимо, рассчитывает устройство |
| Конец трека | не обрабатывается: «Status: Play» остаётся, повторы замирают | stop и stop @ 0 | **claude** (решение владельца 3) |
| Канал DMX | индекс с 0, как в Windows | номер с 1, как на пульте | **claude** (решение владельца 4) |
| Universe | хранится строкой, не применяется | «любой» или фильтр | **claude** |
| DMX и потоки | каждый пакет (~40/с) идёт в главный актор | триггер на очереди сокета, на главный поток — только сработавшая команда | **claude** |
| Настройки | ключи UserDefaults по одному; интерфейс по индексу | JSON `settings.v1`, запись через 0,5 с; интерфейс по имени | **claude.** Порядок интерфейсов на Mac меняется, индекс ненадёжен |
| Аудио | `AVAudioPlayer`; ошибка открытия глушится `try?` | `AVAudioPlayer` + делегат конца трека, сброс позиции на stop | **claude.** Добавлена понятная ошибка битого файла |
| Окно | `WindowGroup`, свой About в меню, кнопок обновления нет | одно окно `Window`, тёмная тема, ↻ списка интерфейсов, подсказки | **claude.** Компоновка у обеих по `MainWindow.xaml` |
| Device lookup | два листа, UDP и TCP; глушить нечего — повторов stop нет | один лист UDP/TCP; повторы play/stop на время листа выключены, как в Windows | **claude** |
| Инструменты проверки | `SocketProbe.app` — зонд на 6 проверок | CLI `epic-probe` (6 команд), `fake-device.py`, `send-artdmx.py` | **claude.** CLI работает из терминала, имитаторы закрывают сеть без железа |
| Сборка `.app` | `Scripts/build-app.sh` → `EpicPlayerMac.app`, 0.1.0, без иконки | `scripts/build-app.sh` → `EpicPlayer.app`, 1.0.0, иконка из `icon.ico` | **claude.** Версия синхронна с Windows |
| Планы | `porting-plan`, `protocol` с подтверждением WindowsReference (15 из 15) | + `app-design`, `final-session`, решения владельца | **claude + статус проверки из master** |

`TcpListener`, `BroadcastSocket`, `InterfaceEnumerator`, `ArtNetParser`,
`PlaybackController`, `AudioPlayer`, `AppSettings`, `AppModel` и окна,
`SocketProbe`. В claude у каждого есть замена. В master было два
блокера: адреса интерфейсов и колбэки сокетов на чужом потоке.
