Всё, что получилось в финальной сессии, в одном месте. Подробный журнал
проверок по пунктам — [`final-session.md`](final-session.md), раздел 11.

- Обе ветки порта сведены в `master`; за основу взята ветка
  `claude/awesome-goodall-q2l9x4`. В старом master было два блокера:

## Утром: порядок проверки

```bash
cd epicplayer-mac
git pull                                 # история переписана — см. «История git»
scripts/build-app.sh && open build/EpicPlayer.app
log stream --predicate 'subsystem == "com.epicplayer.mac"' --level debug   # в отдельном окне
```

1. Разрешить доступ к локальной сети (D21). Пройти руками C2–C8, C12,
   C15, C16. Тестовые файлы лежат в `/tmp/epic-audio`, до перезагрузки:
   wav на 4 и 12 с, m4a с кириллицей в имени, битый mp3.
2. Окно Device lookup с имитатором на этом же Mac. Имитатор запускать
   **до** приложения:
   `python3 scripts/fake-device.py --name "Шоу 1" --same-host --tcp`.
3. `sudo tcpdump -i en0 -n -X 'udp port 333 or udp port 6454 or tcp port 3331'`
   — сверить D6–D13 на проводе.
4. Устройство шоу: `swift run epic-probe lookup en0`, затем этап E.
   Сырые байты ответа (E1) и рабочий адрес объявления (E6) записать в
   журнал и в `protocol.md`.
5. Настоящий пульт (F12), разрешения (D22–D24), устойчивость (G1–G7).
6. `scripts/make-dmg.sh`, образ на другой Mac (H2, H3).

## Особенности и риски

- **Панель Open при первом запуске.** Один раз при самом первом запуске
  нового бандла поверх окна открылась панель Open. Не повторилась ни при
  перезапусках, ни после сброса настроек, ни при запуске копии из нового
  пути. Если появится — записать, после чего.
- **Двойной пакет.** Сразу после Play может уйти второй play @ 0, а после
  конца трека — два stop @ 0 в одну секунду: сетевой таймер идёт
  независимо от команд. Так же работает Windows-версия.
- **Повторный запрос разрешения.** При каждой пересборке меняется ad-hoc
  подпись, и macOS может снова спросить доступ к локальной сети. Это
  уйдёт с подписью Developer ID.
- **Адрес в TCP-объявлении.** Какой нужен устройству — свой или broadcast,
  как в Windows, — неизвестно до проверки (protocol.md, расхождение 4).
  В окне есть переключатель.
- **Формат ответа устройства** известен только до имени (байты 47–58).
  Остальное — по сырым байтам E1.
- **Unicast на свой адрес:333** получает только сокет, открытый первым.
  Важно лишь для имитаторов на том же Mac — отсюда `--same-host`.

## История git

- 17 коммитов `master`, начиная с `ba86f25` (теперь `6dae1d9`), переписаны
  через `git filter-branch --msg-filter`: удалены только строки
  `Co-Authored-By`. Деревья, авторы, даты и порядок коммитов не изменились,
  что проверено по каждой паре старый/новый. Отправлено
  `git push --force-with-lease`.
- 5 коммитов из ветки `claude/…` были подписаны SSH-ключом. После правки
  сообщения подпись не сохраняется — на GitHub они больше не «Verified».
- **В других клонах** (например, на Windows-машине) обычный `git pull`
  не сработает. При отсутствии локальных изменений:
  `git fetch origin && git reset --hard origin/master`.
- Старые коммиты ещё живут в ветке `claude/awesome-goodall-q2l9x4` —
  локально и на GitHub; PR #1 отмечен как слитый. Ветку можно удалить,
  если она больше не нужна.
- Локальная резервная копия `master` до переписывания —
  `backup/master-before-rewrite`. После проверки:
  `git branch -D backup/master-before-rewrite`.
